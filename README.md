# هەژمار | Hezhmar — سیستەمی ژمێریاری و کۆگا

سیستەمێکی فول‌ستاک بۆ **ژمێریاری + کۆگا + فرۆشتن + کڕین** بە **کوردی سۆرانی (RTL)**، ئامادە بۆ دامەزراندن لەسەر **Vercel** لەگەڵ **PostgreSQL**.

## تایبەتمەندییەکان

- داشبۆردی سەرەکی (فرۆشتنی ئەمڕۆ، نەقد، بەهای کۆگا، ئاگاداری کەمی کاڵا)
- کاڵا و پۆل (SKU، نرخی کڕین/فرۆشتن، کەمترین بڕ)
- کڕیار و دابینکەر + باڵانسی قەرز
- پسوڵەی فرۆشتن و کڕین (کۆگا خۆکار نوێ دەبێتەوە)
- جوڵەی کۆگا (چوونەژوورەوە / دەرهێنان / ڕێکخستن)
- خەرجییەکان
- لیستی حیسابات (Chart of Accounts) + تۆماری ژمێریاری (Journal)
- ڕاپۆرت: قازانج و زیان، تاقیکردنەوەی باڵانس، بەهای کۆگا
- ڕێکخستنی کۆمپانیا و دراو (IQD / دینار)

## تەکنەلۆژیا

- Next.js 15 (App Router) + React 19
- Prisma + PostgreSQL (Vercel Postgres / Neon)
- Tailwind CSS — UIی RTL کوردی
- Server Actions بۆ کارەکان

## دامەزراندن لە Vercel

1. Repo ببەستە بە [Vercel](https://vercel.com)
2. **Storage → Postgres** دروست بکە و بە پرۆژەکە ببەستە (`DATABASE_URL`)
3. Deploy بکە — خشتەکان و حیسابە بنەڕەتییەکان لە یەکەم داواکاریدا خۆکار دروست دەبن
4. پشکنین: `/api/health` → دەبێ `ok: true` بگەڕێتەوە
5. بکەرەوە: `/dashboard`

## گەشەپێدانی local

```bash
npm install
cp .env.example .env
# DATABASE_URL بنووسە (Postgres)
npm run db:setup
npm run dev
```

# فرۆشتنی دڵ — Rap Instrumental

Original melancholic Kurdish-flavored rap beat inspired by the *theme* of lost love sold for money.

**Not a cover** of Farhad Zirak — melody, arrangement, and lyrics are original.

| File | Description |
|------|-------------|
| `farhad-inspired-rap-instrumental.mp3` | ~91s instrumental (BPM 86) |
| `lyrics-ku.txt` | Original Sorani rap lyrics |
| `generate_rap_beat.py` | Script that synthesizes the beat |

## Structure
Intro (4) → Verse (8) → Hook (4) → Verse (8) → Hook (4) → Outro (4)

Regenerate:

```bash
python3 generate_rap_beat.py
```
